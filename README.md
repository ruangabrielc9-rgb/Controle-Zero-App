# Catálogo Zero · Bancada Zero

App Android para catalogar a bancada de display: placas, telas, barras de LED, TVs completas,
valores, estoque e as adaptações já feitas (com passo a passo e fotos).

- Os dados e as fotos ficam guardados só no celular. Use o botão **Backup** dentro do app.
- Funciona sem internet.

## Como baixar o APK
Aba **Releases** do repositório (versões "Catálogo Zero"), arquivo `CatalogoZero.apk`.
Para instalar, libere "instalar apps de fontes desconhecidas" no Android.

Esta pasta fica na branch `catalogo`. O controle de TV continua na branch `main`.
