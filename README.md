# Bancada Zero · Controle de serviço (IR)

App Android com emissor infravermelho para abrir menus de serviço de TV (Samsung e LG).
Visual da comunidade Bancada Zero.

- Samsung: Info + Factory, sequência de serviço, navegação e números.
- LG: In-Start e Ez-Adjust (códigos a confirmar no modelo), navegação e números.
- Só funciona em celular Android que tenha emissor infravermelho.

## Como baixar o APK
Aba **Releases** do repositório, arquivo `BancadaZero.apk`.
Para instalar, libere "instalar apps de fontes desconhecidas" no Android.
